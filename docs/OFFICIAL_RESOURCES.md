# LlamaIndex 官方资料索引

本项目固定在 `llama-index 0.14.23` 并通过了本地测试。LlamaIndex 更新较快，继续扩展时应优先查官方文档，并同时核对本项目锁定的版本。

- [官方 Python 文档首页](https://docs.llamaindex.ai/en/stable/)
- [本地与远程数据加载](https://docs.llamaindex.ai/en/stable/module_guides/loading/)
- [Ingestion Pipeline](https://docs.llamaindex.ai/en/stable/module_guides/loading/ingestion_pipeline/)
- [索引概念与模块](https://docs.llamaindex.ai/en/stable/module_guides/indexing/)
- [查询模块](https://docs.llamaindex.ai/en/stable/module_guides/querying/)
- [向量存储集成](https://docs.llamaindex.ai/en/stable/module_guides/storing/vector_stores/)
- [Workflows](https://docs.llamaindex.ai/en/stable/understanding/workflows/)
- [Agents](https://docs.llamaindex.ai/en/stable/understanding/agent/)
- [LlamaIndex GitHub](https://github.com/run-llama/llama_index)

遇到导入路径不一致时，先运行 `python -m pip show llama-index llama-index-core` 确认安装版本，再查看对应版本的文档或包内函数签名。
